# 📰 Prof Manfrim

> Um jornal escrito por uma só voz.

Projeto web desenvolvido com foco em organização, clareza e identidade autoral.  
Este projeto passou por um **rewrite completo**, sendo reestruturado do zero com uma nova arquitetura e aplicação de boas práticas modernas.

---

## 🚀 Sobre o Projeto

O **Prof Manfrim** é uma plataforma autoral com proposta de publicação de textos e reflexões em formato de jornal digital.

Mais do que uma atualização visual, este projeto representa uma evolução técnica, aplicando conceitos de:

- Arquitetura organizada
- Código limpo
- Separação de responsabilidades
- Estrutura escalável

---

## 🛠️ Tecnologias Utilizadas

- PHP
- Laravel
- Blade
- MySQL
- HTML5
- CSS3
- JavaScript

---

## 🧠 Processo de Evolução

Este projeto originalmente foi meu primeiro contato com desenvolvimento web.

Recentemente, decidi realizar um **Project Rewrite**, reescrevendo a aplicação completamente do zero para aplicar:

- Boas práticas aprendidas ao longo do tempo
- Melhor organização estrutural
- Melhor legibilidade
- Melhor manutenção futura

Evoluir também é ter maturidade para reconstruir.
